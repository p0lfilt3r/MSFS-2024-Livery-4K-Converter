MSFS 2024 – Livery 4K Converter
CHANGELOG

Version 1.8 – Original Material Preservation
- Removed the surface-finish checkbox and all roughness/metalness sliders.
- Removed all code paths that deliberately override COMP/ORM material channels.
- Textures within the configured size limit are copied byte-for-byte.
- Oversized textures use the normal resize/re-encode pipeline; resampling and compression may cause technical pixel-level differences.
- Preserves batch processing, responsive window, right-side scrollbar and bilingual interface.

Version 1.7 – Batch Processing and Responsive Window
- Responsive startup window sized to the available display.
- Right-side vertical scrollbar when the full interface does not fit.
- Corrected scrollbar placement in the v1.7 test package; the scrollbar is now on the right edge.
- Source selection automatically fills the sibling destination path with _4K appended.
- Destination folders are created automatically when conversion starts.
- Recursive batch discovery of nested MSFS livery package roots.
- One sibling *_4K output folder per source livery.
- Existing *_4K outputs are cleared and rebuilt after confirmation.
- Existing *_4K folders are excluded from batch source discovery.

Version 1.6 – KTX2P handling
- Removes copied .ktx2p files from the destination package after a successful KTX2 texture resize.
- Logs source/destination KTX2 file-size totals as an estimate.

Version 1.5 – German/English interface
- Added selectable German and English UI.

Version 1.4 – Full package copy
- Copies complete livery package trees and optionally rebuilds layout.json.

Version 1.3 – NVIDIA/BC7
- Added DirectCompute GPU acceleration for BC7 texture conversion.
