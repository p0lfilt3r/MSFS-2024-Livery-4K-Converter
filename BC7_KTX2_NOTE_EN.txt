Version 1.6 – BC7-KTX2, GPU Acceleration and KTX2P Fix
======================================================

BC7-KTX2 data is extracted in raw form from the KTX2 container, passed to DirectXTex
as DDS/BC7, resized, and packaged back into KTX2. The KTX2 DFD and complete Key/Value
metadata, including ASOBO_* keys, are preserved.

VRAM NOTE: MSFS 2024 may load old packed texture data from .ktx2p files even after
individual .ktx2 files have been resized. Microsoft recommends removing KTX2P files
after directly modifying KTX2 textures. Version 1.6 therefore removes all .ktx2p
files from the DESTINATION package only after a successful KTX2 resize. Source files
remain untouched. The simulator then falls back to the regular individual KTX2 files.

For BC7, texconv can use the GPU through DirectCompute:
  -gpu 0     DirectCompute adapter 0 (default)
  -gpu 1     DirectCompute adapter 1 (often NVIDIA on hybrid laptops)
  -nogpu     CPU mode

MSFSLayoutGenerator.exe runs after KTX2P removal and texture conversion so that
layout.json matches the actual package file structure.

Required external tools:
- Microsoft DirectXTex texconv.exe
- Khronos KTX-Software ktx.exe (for KTX2)
- MSFSLayoutGenerator.exe (recommended for complete packages with layout.json)
- Python 3.9+ and Pillow

Original source files are never modified. KTX2P cleanup affects the destination folder
only, never the source folder.
